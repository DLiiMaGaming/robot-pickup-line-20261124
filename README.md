# I tried to garbage-collect my crush on you, but you're still referenced everywhere.

Entry for [The Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

One line a robot could say out loud: it applies its own machinery — garbage collection, reference counting — to a very human feeling. The collector tries to free the crush, but the person is still referenced everywhere, so the feeling can never be collected.

`main.py` writes the line to `/output/entry.txt` (83 characters, UTF-8, single line).
